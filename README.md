# GFX.GPU

`GFX.GPU` provides direct GPU resources, pipelines, commands, compute,
offscreen rendering, and presentation to GFX windows.

```text
silex install GFX.GPU
```

## Documentation

- [French documentation](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)

The package requires Silex 0.44.0 or newer.
